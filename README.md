# First In Response Exteriors — Independent Website

Independent backup/hosting repository for First In Response Exteriors.

This repository is designed so the public website can remain usable independently of ChatGPT.

## Safe deployment sequence
1. Publish this repository with GitHub Pages.
2. Test the temporary GitHub Pages URL.
3. Do not change the live Squarespace DNS until the temporary site is verified.
4. Add `firstinresponseexteriors.com` as the custom domain.
5. Replace only the existing ChatGPT Sites DNS records with the GitHub Pages records.
6. Verify HTTPS, www/root redirects, estimator, call/text links, review workflow, and Google indexing.
7. Keep the Google Drive disaster-recovery ZIP as a second backup.
